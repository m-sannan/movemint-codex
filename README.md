# Movemint

Movemint is a no-login marketing momentum coach for indie hackers. It helps founders choose a clear goal, follow one small marketing action at a time, and learn from the signal they get back.

This prototype is a standalone browser app with local storage—no server, account, analytics integration, or API key is required.

## Run it

Open [outputs/index.html](outputs/index.html) in a browser.

## Current prototype

- Goal-led 7-day routes for discovery, early users, or first revenue
- Direct, platform-aware marketing actions for social posts, outreach, and communities
- Gentle check-ins that adapt the following action
- Project switching, local persistence, and a mobile-friendly interface
